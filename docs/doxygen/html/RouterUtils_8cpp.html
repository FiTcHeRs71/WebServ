◆ writeInFile()

int writeInFile ( const string &  filename,
const string &  body,
string &  written 
)

Ecrit body en binaire dans filename.

0 ok, 400, 500 ; written = path reel

Collision : suffixe _1, _2 avant l'extension.

Ne cree pas le dossier parent : ofstream fail -> 500. Une entree existante qui n'est pas un fichier regulier -> 400. Le '.' d'extension est cherche apres le dernier '/' (pour ne pas matcher le '.' de ./www). Pas d'extension -> suffixe en fin de nom (Makefile -> Makefile_1).

Paramètres
filenameChemin cible (upload_store + '/' + basename).
bodyOctets bruts, peut contenir des NUL.
writtenOut : chemin reellement ecrit (avec suffixe si collision).
Renvoie
0 ok, 400 collision avec un non-fichier, 500 open/write fail.
