const string &  path 
)

check si le prefixe path s'arrete sur une frontiere de segment de l'URI

Evite qu'une location "/img" matche l'URI "/images/logo.png".

Précondition
uri doit avoir path en prefixe (verifie par ServerConfig::Resolve)
path est non vide (garanti par parse_location)
Paramètres
urichemin indique dans la requette HTTP 1.1, query/fragment deja retires
pathchemin indique par le bloc location entrain detre verifier
Renvoie
true si match exact, si path finit par '/', ou si le caractere suivant dans l'uri est un '/'

◆ is_valid_ipv4()

bool is_valid_ipv4 ( const string &  host)

Verifie qu'une chaine est une adresse IPv4 bien formee.

Attend 4 segments numeriques separes par 3 points, chacun <= 255, sans zero non significatif en tete (010 est refuse).

Paramètres
hostLa partie host du token listen (avant le ":").
Renvoie
true si l'IPv4 est valide, false sinon.
