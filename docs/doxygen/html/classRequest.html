Represente une requete HTTP recue par le serveur.

Accumule les octets recus sur le socket et les parse progressivement (ligne de requete, en-tetes, corps).

◆ findChunkData()

bool Request::findChunkData ( )

Accumule les octets de payload du chunk, comme findBody().

Prend min(reste du chunk, _Raw.size()) ; le surplus (CRLF, chunk suivant) reste dans _Raw. Verifie client_max_body_size au fur et a mesure (413).

Renvoie
true si les _CurrentChunkSize octets sont lus (passage a ST_CHUNK_CRLF), false s'il en manque, ou ST_ERROR / 413 si la limite est depassee.
