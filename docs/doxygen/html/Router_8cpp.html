◆ parse_multipart()

bool parse_multipart ( const std::string &  body,
const std::string &  boundary,
vector< TMultipartPart > &  out 
)

Decoupe un body multipart/form-data sur –boundary (RFC 7578, C-10).

Le delimiteur dans le corps est "--" + boundary. Le close porte "--" en plus. Pour chaque part : headers jusqu'au double CRLF, puis octets exacts jusqu'au CRLF qui precede le delimiteur suivant (ce CRLF n'appartient pas au fichier). Data peut contenir des NUL : substr + size, jamais strlen.

Paramètres
bodyCorps HTTP brut.
boundaryValeur de boundary=, sans les '–' (quotes deja retirees).
outParts dans l'ordre, y compris les champs texte (Filename vide).
Renvoie
false si body/boundary vides, delimiteur absent, headers ou close manquants.
